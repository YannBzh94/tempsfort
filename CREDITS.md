# Crédits

- Bruitages des transitions : [UI SFX](https://github.com/romainsimon/uisfx) (jeux « cinematic » et « soft »),
  sons placés dans le domaine public (CC0 1.0).
- Musique libre : recherche via l'API publique d'[Openverse](https://openverse.org). Chaque morceau garde sa
  propre licence, affichée dans l'appli ; le crédit peut être ajouté à la fin du film.
